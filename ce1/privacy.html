Politique de confidentialité

MathAda CE1 — dernière mise à jour : 19 octobre 2026.

Responsable et contact

MathAda CE1 est proposée par Johan Kevin Pages. Pour toute demande liée à la confidentialité : irokhan42@gmail.com. Un parent ou représentant légal peut nous contacter.

Compte, publicité et identité

L’application ne demande pas de compte, de nom d’enfant, d’adresse e-mail, de photographie ni de localisation. Elle ne contient pas de publicité et ne réalise pas de suivi publicitaire entre applications ou sites.

Données sur l’appareil

La progression, les réponses utiles à la reprise d’une séance, les aides utilisées, les erreurs, les réglages, les étoiles et l’état de la base sont conservés localement afin de faire fonctionner le jeu.

Des compteurs pédagogiques locaux résument aussi les séances et questions terminées, les erreurs, les aides et le temps actif par type d’exercice. Ces résumés ne contiennent ni nom ni réponse brute. À partir de la version 1.0 (11), leur envoi à Firebase est activé par défaut. Un parent peut le désactiver dans l’espace parent des réglages ; tout refus déjà enregistré est conservé lors de la mise à jour.

Services techniques

Le projet CE1 inclut Google Firebase et son module de stabilité Crashlytics. L’envoi automatique des rapports de plantage est désactivé dans cette version ; des informations de plantage peuvent être conservées localement par le module. Firebase Analytics est activé par défaut pour améliorer les exercices, sauf si un parent l’a désactivé. Les événements transmis décrivent les séances commencées/terminées, les questions terminées, les erreurs, les aides et le temps actif par type d’exercice, ainsi que la version de l’app. Firebase associe un identifiant aléatoire à l’installation et peut traiter des informations techniques telles que le système, le modèle d’appareil, la langue et la région approximative. Les identifiants publicitaires, la personnalisation publicitaire et les relevés automatiques d’écrans sont désactivés. Les données Firebase de MathAda CP ne sont pas utilisées pour CE1.

Le refus ne modifie pas le jeu. Un parent peut désactiver les statistiques dans Réglages → Confidentialité · Espace parent : la collecte Analytics est alors arrêtée et les données Analytics locales remises à zéro. Google traite les statistiques pour notre compte ; elles sont chiffrées en transit et peuvent être traitées sur son infrastructure mondiale. La durée de conservation des données détaillées dépend des réglages de Google Analytics ; les rapports agrégés peuvent être conservés plus longtemps. Voir les informations de confidentialité Firebase. Crashlytics reste désactivé indépendamment de ce choix.

Avis sur les stores

L’application peut proposer rarement le dialogue d’avis natif d’Apple ou de Google, à un moment calme. Il n’y a pas de récompense en échange d’un avis. Le store gère ce dialogue et les avis selon sa propre politique.

Conservation et suppression

Les données locales restent sur l’appareil tant que l’application y est conservée, sous réserve des fonctions de sauvegarde du système. La réinitialisation du jeu supprime sa progression ; elle ne constitue pas une suppression des éventuels compteurs techniques locaux. La suppression de l’application ou de ses données permet de supprimer ses fichiers locaux.

Une demande d’assistance envoyée par e-mail contient uniquement les informations que le parent choisit de transmettre. Elles servent à traiter sa demande ; nous n’avons pas accès à la progression locale de l’enfant.

Vos demandes

Un parent peut demander des informations, l’accès, la rectification ou la suppression des données éventuellement transmises en nous contactant. La désactivation des statistiques dans l’app arrête les futurs envois ; il ne supprime pas automatiquement les données déjà transmises à Google. Nous ne recevons pas le nom de l’enfant ni sa progression complète. Nous vous expliquerons les informations nécessaires pour traiter une demande, sans demander de données inutiles.

Ce site

Les pages d’assistance sont hébergées sur GitHub Pages. La consultation du site peut entraîner le traitement d’informations techniques de connexion par GitHub selon sa politique de confidentialité. Ces pages n’intègrent pas d’outil publicitaire ni de mesure d’audience ajouté par MathAda.
